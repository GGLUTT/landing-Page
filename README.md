# Landing Page

A responsive landing page template built with modern web development tools and practices. This project provides a solid starting point for creating beautiful, responsive landing pages.

![Landing Page Screenshot](https://i.imgur.com/fOmtqZd.png)

## Live Preview

You can view the landing page here: [DEMO LINK](https://gglutt.github.io/landing-Page/)

## Design Reference

The design follows modern web design principles with responsive layouts and clean aesthetics. It features a minimalist approach with attention to typography, spacing, and visual hierarchy to enhance user experience.

## Technologies Used

- HTML5
- CSS3/SCSS
- JavaScript
- Gulp (task automation)
- Stylelint (CSS linting)
- ESLint (JavaScript linting)
- BEM methodology (CSS naming convention)

## Getting Started

### Viewing Online

Simply visit the [live demo](https://gglutt.github.io/landing-Page/) to view the landing page in your browser.

### Running Locally

1. Clone the repository:
```bash
git clone https://github.com/GGLUTT/landing-Page.git
```

2. Navigate to the project directory:
```bash
cd landing-Page
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm start
```

5. To build for production:
```bash
npm run build
```
